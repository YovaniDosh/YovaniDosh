I'm a **Junior Full-Stack Developer** who enjoys building things for the web and turning ideas into real projects. I like learning by doing, exploring new technologies, and getting better at both frontend and backend development.   
I'm also learning about **cybersecurity** and how to write more secure code. Every project helps me learn something new, solve problems, and grow as a developer.

- I follow a **Mobile First** approach and build responsive designs.
- I care about writing semantic, maintainable, and accessible code.
- I practice Git, GitHub, npm, and technical documentation in every project.
- I'm currently working toward learning Vue.js, databases, and building more complete applications.

> My goal isn't just to finish projects, but to become a developer who can explain and improve every technical decision.
